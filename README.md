# PMM-Rover

A small starter page to build an AI chatbot using Perchance.org.

## How to use

1. Open `index.html` in a browser.
2. Click **Copy prompt**.
3. Visit [perchance.org](https://perchance.org) and open the AI Character Chat tool.
4. Paste the prompt into the character description field and start chatting.

## Customize

Edit the prompt in `index.html` to adjust tone, rules, or add domain knowledge.
